一、项目简介
===========================================================================

本项目是一个前后端分离的小区物业管理系统：
- 后端：Spring Boot 2.7 + MyBatis Plus + Spring Security + JWT
- 前端：Vue 2 + Element UI + ECharts
- 数据库：MySQL 8.0

项目目录结构：
├── backend/           ← 后端 Spring Boot 项目
│   ├── pom.xml        ← Maven 依赖配置文件
│   └── src/           ← Java 源代码
├── frontend/          ← 前端 Vue 项目
│   ├── package.json   ← npm 依赖配置文件
│   └── src/           ← Vue 源代码
├── 测试账号.txt       ← 系统测试账号信息
├── 部署运行说明文档.txt  ← 本文档
└── 代码说明文档.txt     ← 代码结构说明

二、运行环境要求
===========================================================================

你的电脑需要安装以下软件（下面会详细讲解每一个的安装步骤）：

1. JDK 17（Java 17）       — 用于运行后端 Spring Boot
2. Apache Maven 3.6+       — 用于构建后端项目、下载依赖
3. MySQL 8.0               — 数据库，存储系统数据
4. Node.js 16+             — 用于运行前端 Vue 项目
5. npm（随 Node.js 自动安装）— 用于管理前端依赖

操作系统：Windows 10/11 均可

===========================================================================
三、第一步：安装 JDK 17（Java 开发工具包）
===========================================================================

【检查是否已安装】
打开命令提示符（按 Win+R，输入 cmd，回车），输入：
    java -version

如果显示类似 "java version 17.x.x" 的信息，说明已安装，可跳过本步骤。

【下载】
1. 打开浏览器，访问 Oracle 官网：
   https://www.oracle.com/java/technologies/downloads/#jdk17-windows

   或者使用国内镜像（推荐，下载更快）：
   https://mirrors.huaweicloud.com/java/jdk/17.0.2+8/

2. 下载 Windows x64 Installer（.exe 文件）
   文件名类似：jdk-17_windows-x64_bin.exe

【安装】
1. 双击下载的 .exe 文件
2. 一路点击 "下一步(Next)"
3. 安装路径建议保持默认（如 C:\Program Files\Java\jdk-17）
4. 安装完成后点击 "关闭(Close)"

【配置环境变量（重要！）】
1. 右键点击 "此电脑" → "属性" → "高级系统设置" → "环境变量"
2. 在 "系统变量" 中：
   a. 点击 "新建"：
      变量名：JAVA_HOME
      变量值：C:\Program Files\Java\jdk-17（你的实际安装路径）
   b. 找到 "Path" 变量，双击打开，点击 "新建"，添加：
      %JAVA_HOME%\bin
3. 全部点 "确定" 保存

【验证安装】
重新打开命令提示符，输入：
    java -version
    javac -version

如果都能正确显示版本号（17.x.x），说明安装成功。

===========================================================================
四、第二步：安装 Maven（Java 项目构建工具）
===========================================================================

【检查是否已安装】
打开命令提示符，输入：
    mvn -version

如果显示版本信息，可跳过本步骤。

【下载】
1. 访问 Maven 官网：https://maven.apache.org/download.cgi
2. 下载 "Binary zip archive"
   文件名类似：apache-maven-3.9.6-bin.zip

   国内镜像下载（更快）：
   https://mirrors.aliyun.com/apache/maven/maven-3/

【安装】
1. 将下载的 zip 文件解压到一个简单的路径，例如：C:\apache-maven-3.9.6
   注意：路径中不要有中文和空格！

【配置环境变量】
1. 右键 "此电脑" → "属性" → "高级系统设置" → "环境变量"
2. 在 "系统变量" 中：
   a. 点击 "新建"：
      变量名：MAVEN_HOME
      变量值：C:\apache-maven-3.9.6（你的实际解压路径）
   b. 找到 "Path" 变量，双击打开，点击 "新建"，添加：
      %MAVEN_HOME%\bin
3. 全部点 "确定" 保存

【配置 Maven 国内镜像（加速依赖下载，强烈推荐！）】
1. 打开文件：C:\apache-maven-3.9.6\conf\settings.xml
2. 找到 <mirrors> 标签（大约在第 146 行），在其中添加：

   <mirror>
     <id>aliyunmaven</id>
     <mirrorOf>*</mirrorOf>
     <name>阿里云公共仓库</name>
     <url>https://maven.aliyun.com/repository/public</url>
   </mirror>

   添加后 <mirrors> 部分应该看起来像这样：
   <mirrors>
     <mirror>
       <id>aliyunmaven</id>
       <mirrorOf>*</mirrorOf>
       <name>阿里云公共仓库</name>
       <url>https://maven.aliyun.com/repository/public</url>
     </mirror>
   </mirrors>

3. 保存文件

【验证安装】
重新打开命令提示符，输入：
    mvn -version

显示类似以下信息即表示安装成功：
    Apache Maven 3.9.6
    Java version: 17.x.x

五、第三步：安装 MySQL 8.0（数据库）
===========================================================================

【检查是否已安装】
打开命令提示符，输入：
    mysql --version

如果显示版本信息，可跳过安装步骤（但仍需确认数据库已启动）。

【下载】
1. 访问 MySQL 官网：https://dev.mysql.com/downloads/installer/
2. 下载 MySQL Installer for Windows
   选择 "mysql-installer-community-8.0.xx.msi"（较大的那个，约 300MB）

   或者直接下载 MySQL 免安装版：
   https://dev.mysql.com/downloads/mysql/
   选择 "ZIP Archive" 版本

【安装（使用 Installer 版）】
1. 双击下载的 .msi 文件
2. 选择 "Developer Default" 或 "Server only"
3. 点击 "Execute" 安装所有组件
4. 配置步骤：
   - Type and Networking：保持默认（端口 3306）
   - Authentication Method：选择 "Use Legacy Authentication Method"
   - Accounts and Roles：
     ★★★ 设置 root 密码为：root ★★★
     （如果你设置了其他密码，后面需要修改配置文件）
   - Windows Service：保持默认，勾选 "Start the MySQL Server at System Startup"
5. 点击 "Execute" 完成配置
6. 点击 "Finish"

【配置环境变量（可选但推荐）】
将 MySQL 的 bin 目录添加到 Path 中：
    C:\Program Files\MySQL\MySQL Server 8.0\bin

【验证安装和启动】
打开命令提示符，输入：
    mysql -u root -p

输入密码 root（输入时不会显示），如果进入了 mysql> 提示符，说明安装成功。
输入 exit 退出。

【确保 MySQL 服务正在运行】
方法1：按 Win+R，输入 services.msc，找到 MySQL80，确保状态为 "正在运行"
方法2：命令提示符输入：net start mysql80

★★★ 重要提示 ★★★
本项目默认数据库配置为：
- 地址：localhost:3306
- 用户名：root
- 密码：root

如果你的 MySQL 密码不是 root，请在后面第七步修改配置文件。

数据库会在后端第一次启动时自动创建（property_db），无需手动创建！

六、第四步：安装 Node.js（前端运行环境）
===========================================================================

【检查是否已安装】
打开命令提示符，输入：
    node -v
    npm -v

如果都显示版本号（node v16+ 和 npm 8+），可跳过本步骤。

【下载】
1. 访问 Node.js 官网：https://nodejs.org/
2. 下载 LTS（长期支持）版本，例如 v18.x 或 v20.x
   文件名类似：node-v18.xx.x-x64.msi

【安装】
1. 双击下载的 .msi 文件
2. 一路点击 "Next"，全部保持默认即可
3. 点击 "Install" → "Finish"

【配置 npm 国内镜像（加速依赖下载，强烈推荐！）】
打开命令提示符，输入：
    npm config set registry https://registry.npmmirror.com

【验证安装】
重新打开命令提示符，输入：
    node -v
    npm -v

都显示版本号即表示安装成功。

===========================================================================
七、第五步：配置数据库连接（仅在密码不是 root 时需要）
===========================================================================

如果你安装 MySQL 时设置的 root 密码是 "root"，可以跳过此步骤。

如果你的 MySQL root 密码不是 "root"，需要修改后端配置文件：

1. 用记事本打开文件：
   backend\src\main\resources\application.yml

2. 找到以下内容（大约在第 4-8 行）：

   spring:
     datasource:
       url: jdbc:mysql://localhost:3306/property_db?...
       username: root
       password: root

3. 将 password: root 中的 root 改为你的实际 MySQL 密码

4. 如果你的 MySQL 端口不是默认的 3306，也需要修改 url 中的端口号

5. 保存文件

八、第六步：启动后端（Spring Boot）
===========================================================================

★★★ 启动前确保 MySQL 服务已经在运行 ★★★

【方法一：使用命令行启动（推荐）】

1. 打开命令提示符（cmd）或 PowerShell
2. 进入后端目录：
   cd "你的项目路径\backend"
   例如：
   cd "F:\26毕设2\基于Spring Boot的小区物业管理系统设计与实现\backend"

3. 首次运行，先下载依赖（这一步可能需要几分钟，取决于网速）：
   mvn clean install -DskipTests

   如果出现 BUILD SUCCESS 字样，说明依赖下载成功。

4. 启动后端：
   mvn spring-boot:run

5. 等待启动完成，当你看到以下信息时说明启动成功：
   "Started PropertyApplication in x.xxx seconds"
   "示例数据初始化完成，所有账号密码均为 123456"

   后端运行在：http://localhost:8089

★★★ 注意：不要关闭这个命令行窗口！后端在此窗口中运行 ★★★

【方法二：使用 IDEA/Eclipse 启动】

1. 用 IntelliJ IDEA 或 Eclipse 打开 backend 目录
2. 等待 IDE 自动下载 Maven 依赖
3. 找到主类：src/main/java/com/property/PropertyApplication.java
4. 右键 → Run 运行

【后端启动成功标志】
- 控制台显示 Spring Boot 的 Banner（大的 ASCII 字符画）
- 显示 "Tomcat started on port(s): 8089"
- 显示 "Started PropertyApplication in x.xxx seconds"
- 显示 "示例数据初始化完成，所有账号密码均为 123456"

【可能遇到的问题】

问题1：提示 "mvn 不是内部或外部命令"
解决：确保 Maven 的 bin 目录已添加到系统 Path 环境变量中，然后重新打开命令行。

问题2：提示 "java.sql.SQLException: Access denied"
解决：检查 application.yml 中的数据库用户名和密码是否正确。

问题3：提示 "Communications link failure"
解决：MySQL 服务没有启动，请在系统服务中启动 MySQL。

问题4：提示端口被占用
解决：修改 application.yml 中 server.port 的值（如改为 8090），
同时修改前端的 vue.config.js 中的代理目标地址。

九、第七步：启动前端（Vue）
===========================================================================

★★★ 请确保后端已经成功启动后，再启动前端 ★★★

1. 新开一个命令提示符窗口（不要关闭后端的窗口！）
2. 进入前端目录：
   cd "你的项目路径\frontend"
   例如：
   cd "F:\26毕设2\基于Spring Boot的小区物业管理系统设计与实现\frontend"

3. 首次运行，先安装前端依赖（需要几分钟）：
   npm install

   如果出现 "added xxx packages" 字样，说明依赖安装成功。

   如果安装很慢或失败，确保已配置国内镜像：
   npm config set registry https://registry.npmmirror.com
   然后重新执行 npm install

4. 启动前端开发服务器：
   npm run serve

5. 等待编译完成，当你看到以下信息时说明启动成功：
   "App running at:"
   "- Local:   http://localhost:8081/"

   前端运行在：http://localhost:8081

★★★ 注意：不要关闭这个命令行窗口！前端在此窗口中运行 ★★★

【前端启动成功标志】
- 显示 "DONE  Compiled successfully"
- 显示访问地址 http://localhost:8081/

【可能遇到的问题】

问题1：npm install 失败，报 ERESOLVE 错误
解决：执行 npm install --legacy-peer-deps

问题2：启动后访问页面空白
解决：清除浏览器缓存，或用无痕模式打开

问题3：页面提示网络错误、接口 404
解决：确保后端已经在 8089 端口成功启动

十二、常见问题 FAQ
===========================================================================

Q1: 为什么登录后页面空白或报错？
A: 请确保后端（localhost:8089）已经启动成功。打开浏览器访问
   http://localhost:8089/api/auth/info，如果返回 JSON 数据，说明后端正常。

Q2: 为什么图表不显示数据？
A: 图表数据来自真实的数据库查询。首次启动时数据会自动初始化。
   如果图表为空，检查后端日志是否显示"示例数据初始化完成"。

Q3: 为什么修改了数据后页面没有更新？
A: 大多数操作会自动刷新列表。如果没有，请手动刷新页面（按 F5）。

Q4: 数据库如何查看？
A: 推荐使用 Navicat、DBeaver 或 MySQL Workbench 连接：
   - 主机：localhost
   - 端口：3306
   - 用户名：root
   - 密码：root
   - 数据库名：property_db

Q5: 如何重置所有数据？
A: 删除 property_db 数据库，然后重新启动后端，数据会自动重新初始化。
   在 MySQL 中执行：DROP DATABASE property_db;
   然后重启后端即可。

Q6: 端口被占用怎么办？
A: 后端端口修改：编辑 backend/src/main/resources/application.yml 中的
   server.port 值。
   前端端口修改：编辑 frontend/vue.config.js 中的 port 值。
   注意：如果修改了后端端口，还需要修改 frontend/vue.config.js 中代理
   target 的端口。

Q7: 如何在生产环境部署？
A: 后端：执行 mvn clean package -DskipTests，在 target 目录下生成
   .jar 文件，使用 java -jar xxx.jar 运行。
   前端：执行 npm run build，将 dist 目录下的文件部署到 Nginx。
